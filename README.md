Flutter Shopping App

A modern grocery shopping app built with Flutter, featuring a clean and responsive design. The app fetches and displays products and categories from a live API, ensuring dynamic and up-to-date content. Users can explore products seamlessly with smooth hero animations on product cards and elegant sliding transitions between screens.

Key Features:

Dynamic screens tailored for grocery shopping, showing products and categories from an API.

Hero animations for product detail navigation and smooth sliding screen transitions.

Built following the DRY principle with MVVM/Clean Architecture.

State management implemented using Bloc or Provider for scalable and maintainable code.

Proper API handling and animations for an engaging user experience.
